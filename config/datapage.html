WHOI Glider Data

Within this site, you can access plots of data from WHOI glider deployments. Plots from gliders that are currently deployed are updated every few hours as new data are received via satellite. Plots from archived deployments are based on post-processed and quality controlled data.

To access realtime plots, go here: gliders.whoi.edu/data/realtime

To access archived plots, go here: gliders.whoi.edu/data/archive

Most of our data are publicly available. Near-real time data are accessible via the US IOOS Glider Data Assembly Center. To access post-processed data in NetCDF format with permanent citation information, please visit spraydata.ucsd.edu. Post-processed data should be used for nearly all analyses.
